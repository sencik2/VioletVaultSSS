# Violet Vault — AppStudio Android Build

Проект подготовлен как обычный Android Gradle-проект для импорта в Android-конструктор/IDE.

## Сборка
1. Распакуй ZIP.
2. В AppStudio выбери импорт существующего Android-проекта или импорт из ZIP/GitHub (если такой пункт есть в твоей версии).
3. Открой корневую папку `VioletVault`.
4. Дождись загрузки Gradle-зависимостей.
5. Запусти Build / Assemble APK.
6. Полученный debug APK можно установить на телефон.

## Что внутри
- Kotlin + Jetpack Compose
- Material 3
- Фиолетовая тёмная тема
- Экран мастер-пароля
- Пароли и заметки
- Поиск
- Показ/скрытие пароля
- Настройки/информация

## Важно
Это пока UI/демо-версия. Не вводи настоящие пароли: данные пока не защищены полноценным постоянным шифрованным хранилищем.
